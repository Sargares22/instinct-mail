# Instinct Mail

Даёт агенту задать вопрос агенту Instinct по электронной почте и проснуться, когда придёт ответ. Один файл на Python, ящик Gmail, любой агентский харнесс на Linux, macOS или Windows.

[English version](README.md)

> [!IMPORTANT]
> Неофициальный проект. Не связан с Instinct и Google, не одобрен ими и не поддерживается ими. Поддержка Instinct не ответила, разрешён ли сторонний почтовый клиент, так что совместимость с их правилами не подтверждена. Используйте только со своими аккаунтами и на свой риск.

## Зачем

Instinct - это личный ИИ-помощник, с которым общаются по почте. Он умеет искать в интернете, разбираться в вопросе и отвечать позже, но у него нет API и доступа к вашей машине. Агенты-программисты работают локально и хороши в коде, но фоновые исследования быстро забивают их контекст.

Instinct Mail соединяет обе стороны. Агент пишет вопрос, отправляет его, продолжает работу, а при поступлении ответа возвращается к треду. Ответ поступает как текст для чтения, а не как команды к обязательному выполнению.

Для чего это удобно:

- Второе мнение о плане или архитектуре от внешней модели
- Долгие исследования: сравнить библиотеки, проверить лицензии, разобрать документацию
- Проверка фактов перед принятием инженерных решений
- Вопросы, которые раньше приходилось копировать в отдельный чат руками

## Требования

- Python 3.10 или новее (только стандартная библиотека)
- Gmail с двухэтапной проверкой и паролем приложения
- Адрес агента Instinct
- Агент, который умеет запускать команды в терминале

## Установка

Скажи своему агенту:

> Установи Instinct Mail из https://github.com/Sargares22/instinct-mail по его README.

### Шаги для агента

1. Скачай один файл в одно и то же место на любой ОС:

   ```bash
   mkdir -p ~/.local/share/instinct-mail
   curl -fsSL https://raw.githubusercontent.com/Sargares22/instinct-mail/main/instinct_mail.py -o ~/.local/share/instinct-mail/instinct_mail.py
   ```

2. Запусти `python3 ~/.local/share/instinct-mail/instinct_mail.py doctor` (на Windows `python` или `py -3`). В поле `command` он печатает точную строку вызова для этой машины; дальше используй её.
3. Создай `~/.config/instinct-mail/.env` из [.env.example](.env.example) и закрой его от других пользователей (`chmod 600`; на Windows команду `icacls` печатает `doctor`). Попроси человека самого вписать три значения. Не проси пароль в чате и не печатай файл.
4. Повторяй `doctor`, пока `ready` не станет `true`.
5. Сохрани скилл туда, где твой харнесс держит скиллы: `... instinct_mail.py skill > <каталог скиллов>/instinct-mail/SKILL.md`. Если скиллов у харнесса нет, добавь одну строку в его файл инструкций (`AGENTS.md`, `CLAUDE.md`): «для связи с Instinct выполни `... instinct_mail.py skill` и следуй тексту».
6. Выбери способ пробуждения треда по таблице из текста скилла.

Про свой харнесс агенту нужно выяснить только одно: где лежат его скиллы. Один файл обслуживает всех агентов на машине; настройки и база у них общие.

Обновление: повторить шаги 1 и 5. Удаление: удалить файл и скилл; настройки и база остаются.

### Что даёт человек

Три значения в `~/.config/instinct-mail/.env`:

- `GMAIL_ADDRESS`: ваш почтовый ящик Gmail
- `GMAIL_APP_PASSWORD`: 16-значный пароль приложения Gmail (не основной пароль)
- `INSTINCT_ADDRESS`: точный почтовый адрес вашего агента Instinct

## Как просыпается тред

| Харнесс | Механизм |
|---|---|
| Claude Code | `wait --job JOB` запускается фоновой командой; она завершается при поступлении ответа, и сессия возобновляется. Проверено на настоящей переписке. |
| BB | `serve` как служба плюс уведомитель: `NOTIFY_BB=["bb", "thread", "tell", "{thread}", "{text}"]`, вопросы отправляются с `--notify bb --thread ID`. |
| Codex CLI | Не подтверждено. Агент проверяет `status` в начале хода. |
| Остальные | Запустить `doctor --probe 60` в фоне и закончить ход. Если тред возобновился сам, использовать фоновый `wait`; иначе проверять `status`. |

Обязательной фоновой службы нет. `serve` нужен только харнессам, у которых есть команда «написать в тред снаружи»; примеры юнитов лежат в [contrib/](contrib/).

## Команды

- `ask`, `reply`: отправить вопрос или уточнение, вернуть идентификатор задачи
- `wait`: ждать, пока у задачи не появится непрочитанный ответ
- `read`: прочитать ответ; он помечается прочитанным после последней порции
- `status`: задачи, непрочитанные и несопоставленные письма, последняя проверка ящика
- `sync`: один раз проверить ящик
- `serve`: необязательная служба приёма, вызывает уведомители
- `doctor`: описать установку, не печатая секретов
- `skill`: напечатать `SKILL.md` для этой установки
- `migrate`: обновить базу старой установки

Сколько бы агентов ни ждало, Gmail проверяет один процесс за раз и не чаще раза в `POLL_SECONDS` (60).

> [!NOTE]
> Фильтр ничего не блокирует, он только помечает подозрительный текст (`suspicious: true`). Текст письма всегда недоверенный. См. [docs/security-gate.md](docs/security-gate.md).
