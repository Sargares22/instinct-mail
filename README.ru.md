# Instinct Mail

Даёт агенту BB задать вопрос агенту Instinct по электронной почте и получить ответ прямо в свой тред. Почтовый мост через Gmail для Linux (`systemd --user`) и macOS (`launchd`).

[English version](README.md)

> [!IMPORTANT]
> Неофициальный проект. Не связан с Instinct и Google, не одобрен ими и не поддерживается ими. Поддержка Instinct не ответила, разрешён ли сторонний почтовый клиент, так что совместимость с их правилами не подтверждена. Используйте только со своими аккаунтами и на свой риск.

## Зачем

Instinct - это личный ИИ-помощник, с которым общаются по почте. Он умеет искать в интернете, разбираться в вопросе и отвечать позже, но у него нет API и доступа к вашей машине. Агенты BB работают локально и хороши в коде, но фоновые исследования быстро забивают их контекст.

Instinct Mail соединяет обе стороны. Агент BB пишет вопрос, отправляет его, продолжает работу, а при поступлении ответа просыпается. Ответ поступает как текст для чтения, а не как команды к обязательному выполнению.

Для чего это удобно:

- Второе мнение о плане или архитектуре от внешней модели
- Долгие исследования: сравнить библиотеки, проверить лицензии, разобрать документацию
- Проверка фактов перед принятием инженерных решений
- Вопросы, которые раньше приходилось копировать в отдельный чат руками

## Требования

- Linux с `systemd --user` или macOS (`launchd`)
- BB в `PATH` (`bb`)
- Python 3.10 или новее
- Gmail с двухэтапной проверкой и паролем приложения
- Адрес агента Instinct

## Установка через агента

Скажи своему агенту:
> Установи Instinct Mail из https://github.com/Sargares22/instinct-mail и настрой Gmail.

Команда для быстрой установки в одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/Sargares22/instinct-mail/main/install.sh | bash
```

### Что агент сделает сам

- Скачает репозиторий, положит файлы в `~/.local/share/instinct-mail` и добавит `instinct-mail` в `~/.local/bin`
- Зарегистрирует навык `instinct-mail` для BB
- Настроит и запустит фоновую службу (`systemd --user` на Linux или LaunchAgent на macOS)
- Проверит статус службы через `instinct-mail status`

### Что агент спросит у человека

Для работы нужны параметры в `~/.config/instinct-mail/.env`:
- `GMAIL_ADDRESS`: ваш почтовый ящик Gmail
- `GMAIL_APP_PASSWORD`: 16-значный пароль приложения Gmail (не основной пароль)
- `INSTINCT_ADDRESS`: точный почтовый адрес вашего агента Instinct

После заполнения `.env` проверь статус:

```bash
instinct-mail status
```

Служба перечитывает `.env` на каждом цикле, пока данные не заполнены, и подхватывает их без перезапуска.

### Как пользоваться дальше

Когда почта настроена, агент сам использует установленный навык:
- `instinct-mail ask`: отправляет вопрос в Instinct и возвращает идентификатор задачи
- `instinct-mail read`: читает поступивший ответ
- `instinct-mail status`: показывает статус службы, неподтверждённые письма и ошибки

> [!NOTE]
> Фильтр ничего не блокирует, он только помечает подозрительный текст (`suspicious: true`). Текст письма всегда недоверенный.

Удаление: `./install.sh --uninstall` (пароли и база остаются).
