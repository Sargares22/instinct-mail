# Instinct Mail

Даёт агенту BB задать вопрос агенту Instinct по электронной почте и получить ответ обратно в свой тред. Небольшой мост через Gmail для Linux с `systemd --user`.

[English version](README.md)

> [!IMPORTANT]
> Неофициальный проект. Не связан с Instinct и Google, не одобрен ими и не поддерживается ими. Поддержка Instinct не ответила, разрешён ли сторонний почтовый клиент, так что совместимость с их правилами не подтверждена. Используйте только со своими аккаунтами и на свой риск.

## Зачем

Instinct - это личный ИИ-помощник, с которым можно общаться по почте. Он умеет искать в интернете, разбираться в вопросе и отвечать позже, но у него нет API и доступа к вашей машине. Агенты BB работают на вашей машине и хороши в коде, но каждое исследование съедает их контекст.

Instinct Mail соединяет эти две стороны. Агент BB пишет вопрос, отправляет его, продолжает работать, а когда приходит ответ, его будят. Ответ приходит как текст, который агент читает, а не как команды, которые он обязан выполнять.

Для чего это удобно:

- Второе мнение о плане или архитектуре от кого-то вне кодовой базы
- Долгие исследования: сравнить библиотеки, проверить лицензии, перерыть документацию
- Проверка фактов, на которые агент собирается опереться
- Вопросы, которые вы и так вставляли бы в окно чата руками, теперь уходят прямо из треда

## Как это работает

Команда `ask` отправляет обычное текстовое письмо с вашего Gmail на адрес Instinct. Фоновая служба опрашивает Gmail по IMAP, берёт только письма, где отправитель точно совпадает с этим адресом, связывает ответ с запросом по заголовкам письма и будит тред BB, который спрашивал. Агент читает ответ командой `read`. Ответ считается недоверенным текстом. Сканер по шаблонам помечает подозрительное содержимое, но это не песочница и безопасным письмо он не делает.

## Что нужно

- Linux или WSL с `systemd` для пользовательской сессии
- BB в `PATH`
- Python 3.10 или новее
- Gmail с двухэтапной проверкой и паролем приложения
- Почтовый адрес вашего агента Instinct

Без `sudo`, без системных пакетов, без зависимостей Python.

## Установка

```bash
./install.sh
```

Потом откройте `~/.config/instinct-mail/.env` и заполните:

- `GMAIL_ADDRESS`: ваш аккаунт Gmail
- `GMAIL_APP_PASSWORD`: пароль приложения, не пароль от аккаунта
- `INSTINCT_ADDRESS`: точный адрес вашего агента Instinct

После правки перезапустите службу:

```bash
systemctl --user restart instinct-mail.service
```

Установщик кладёт код в `~/.local/share/instinct-mail`, команду `instinct-mail` в `~/.local/bin`, навык BB в `~/.bb/skills/instinct-mail`, состояние в `~/.local/state/instinct-mail`. Пароли остаются на вашей машине. Если сменили установку Node, которой пользуется `bb`, запустите `./install.sh` ещё раз.

## Каждый день

```bash
instinct-mail status
systemctl --user restart instinct-mail.service
./install.sh --uninstall   # пароли и состояние остаются
```

Команды `ask`, `reply` и `read` для агента описаны в установленном навыке.
